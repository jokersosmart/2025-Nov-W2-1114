# 驗證與確認計畫品質檢查清單

**目的**: 驗證 SEooC 開發計畫中的 V&V(Verification & Validation)測試檢查計畫是否完整、可執行且符合 ISO-26262 ASIL B 等級要求。此檢查清單作為「V&V 計畫的單元測試」,檢查測試計畫本身的品質,而非檢查測試執行結果。

**名詞解釋**: V&V = Verification and Validation = 驗證與確認 = 測試檢查
- **Verification(驗證)**: 檢查「我們做的東西對不對」(程式碼是否符合設計規格)
- **Validation(確認)**: 檢查「我們做的東西是不是客戶要的」(晶片功能是否符合客戶需求)

**建立日期**: 2025-11-17  
**適用範圍**: specs/001-seooc-iso26262-asil-b/spec.md  
**深度等級**: 正式級(外部評估準備)  
**使用階段**: V&V 計畫制定 → 測試案例設計 → 測試執行 → 覆蓋率分析 → 外部評估準備  
**ISO-26262 主要參考**: Part-4 §7 (System Integration & Testing), §8 (Verification & Validation), Table 9 (Coverage Metrics)
